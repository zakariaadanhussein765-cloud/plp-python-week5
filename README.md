# PLP Python Week 5 Assignment

* `countdown.py` — A countdown program that uses a loop to count down to zero.
* `guess_game.py` — A guessing game that uses a `while` loop and conditionals to check guesses.
* `spell_it_out.py` — A program that prints each letter of a word separately, numbers the letters, and counts them.

A `while` loop is useful when you want a program to keep repeating as long as a condition is true, especially when you don't know exactly how many repetitions are needed. A `for` loop is better when you want to repeat something over a known sequence or a specific number of items.
